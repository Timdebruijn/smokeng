# Documentation screenshots

Drop these PNGs here and the docs pick them up — the references and captions are
already in place. Capture at your display's full resolution; the UI is theme-aware,
so either light or dark is fine as long as they are consistent.

Set the time range to **15m** so a recent incident's loss band does not dominate the
frame, and untick any empty "from <agent>" rows in the sidebar for a cleaner shot.
